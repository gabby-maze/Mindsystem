**Build a single-page lead generation landing page with the following spec:**

**Purpose:** Capture name + email in exchange for a free video training. On submit, show a thank-you state and (eventually) trigger an email with the video link.

**Page structure (single scrolling page, in this order):**
1. Header/logo area — leave placeholder for logo image, transparent background
2. Hero section: eyebrow text, headline, subheadline, video embed placeholder (16:9 responsive container)
3. "What You'll Learn" section: 3 bullet points, each with a simple icon placeholder (checkmark or similar)
4. Clarity Call CTA block: headline, body copy, button linking to Calendly (opens in new tab)
5. Opt-in form section: headline, First Name field, Email field, submit button, micro-copy below button
6. Footer: credibility line, small text

**Visual style:**
- Base background: black
- Accent colors: hot pink, purple, and teal (use as highlights on headline text, button, bullet icons — not as full-section backgrounds)
- Headline font: "Permanent Marker" (Google Font) — bold, hand-drawn energy
- Body/UI font: "Oswald" (Google Font) — clean, condensed, athletic
- Aesthetic reference: 80s retro sports poster — bold color blocking, slight grain/texture is welcome if easy to implement, but prioritize clean readability on mobile over texture effects
- Fully responsive — assume most traffic is mobile (Instagram click-throughs)

**Form behavior:**
- First Name and Email are both required fields
- On submit: validate email format client-side
- POST the form data to a webhook URL — use a placeholder constant `GHL_WEBHOOK_URL` at the top of the file so it can be swapped for the real GoHighLevel webhook URL later
- On successful submit: replace the form with the thank-you message + a second "Book Your Clarity Call" button (copy provided above). Do not navigate away from the page.
- On failed submit: show an inline error message near the form, do not lose the user's entered data
- Use a constant `CALENDLY_URL = "https://calendly.com/gabby-mazeperformance/clarity-call-with-gabby"` at the top of the file, referenced by both the mid-page Clarity Call button and the post-submit Clarity Call button. Both buttons should open Calendly in a new tab.

**Technical notes:**
- Single HTML/CSS/JS page is fine, or a simple React component if that's the project's existing stack — match whatever framework the Replit project is already using
- No backend database needed for this build — the webhook POST is the only data handoff
- Keep the page lightweight — no unnecessary libraries
- Add basic SEO meta tags (title, description) using the headline and subheadline copy above
