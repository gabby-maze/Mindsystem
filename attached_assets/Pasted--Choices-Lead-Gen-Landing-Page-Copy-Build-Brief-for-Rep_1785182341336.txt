**Build a single-page lead generation landing page with the following spec:**

**Purpose:** Capture First Name, Last Name, Email, and Phone in exchange for access to a free video training. This page needs a higher-conversion treatment than previous lead pages — most of the page content should visually communicate "there's more here, unlock it" rather than just listing plain bullet points.

**Page structure (single scrolling page, in this order):**
1. Header/logo area — leave placeholder for logo image, transparent background
2. Hero section: eyebrow text, headline, subheadline
3. "What You'll Learn" teaser section: 6 items, styled as a locked/teased list (see visual treatment below)
4. "Why This Matters" section: two short paragraphs, no lock treatment, this is persuasive copy, not gated content
5. Clarity Call CTA block: headline, body copy, button linking to Calendly (opens in new tab)
6. Opt-in form section: headline, First Name, Last Name, Email, Phone fields, submit button, micro-copy below button
7. Footer: credibility line, small text

**Visual treatment for the teaser section (important, this is the conversion upgrade):**
- Each of the 6 items should have a small lock icon next to it
- Style each item as a card with a subtle blurred or dimmed overlay effect on part of the text, or a "locked" badge in the corner, to visually signal there's more behind each one than what's shown
- Do not fully blur the teaser text into unreadability, people need to be able to read the hook itself, just visually signal that the full explanation is gated
- On hover/tap (mobile), a small lock icon can pulse or highlight to reinforce the "unlock this" feeling without being gimmicky

**Visual style:**
- Base background: black
- Accent colors: hot pink, purple, and teal (use as highlights on headline text, button, lock icons, list numbering, not as full-section backgrounds)
- Headline font: "Permanent Marker" (Google Font)
- Body/UI font: "Oswald" (Google Font)
- Aesthetic reference: same visual system as the other MazePerformance funnel pages, keep this consistent rather than introducing a new look
- Fully responsive, assume most traffic is mobile (Instagram click-throughs from the CHOICES comment trigger)

**Form behavior:**
- First Name, Last Name, Email, and Phone are all required fields
- On submit: validate email format client-side
- POST the form data to a webhook URL, use a placeholder constant `GHL_WEBHOOK_URL` at the top of the file so it can be swapped for the real GoHighLevel webhook URL later
- On successful submit: replace the form with the thank-you message + a second "Book Your Clarity Call" button (copy provided above). Do not navigate away from the page.
- On failed submit: show an inline error message near the form, do not lose the user's entered data
- Use a constant `CALENDLY_URL = "https://calendly.com/gabby-mazeperformance/clarity-call-with-gabby"` at the top of the file, referenced by both the mid-page Clarity Call button and the post-submit Clarity Call button. Both buttons should open Calendly in a new tab.

**Technical notes:**
- Single HTML/CSS/JS page is fine, or a simple React component if that's the project's existing stack, match whatever framework the Replit project is already using
- No backend database needed for this build, the webhook POST is the only data handoff
- Keep the page lightweight, no unnecessary libraries beyond what's needed for the lock/blur visual effect (pure CSS should be enough, no need for a JS library)
- Add basic SEO meta tags (title, description) using the headline and subheadline copy above
